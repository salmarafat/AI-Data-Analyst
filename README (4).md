# 📖 Project Overview

A fully local-first AI application for business data analysis:
Upload a CSV/Excel file → automatic inspection & summary → visualizations → statistical analysis →
business insights and recommendations from a local AI model → a chatbot that understands your
questions and actually runs Python analysis on your data.

# ✨ Features

Upload and analyze CSV and Excel datasets.
Automatic dataset summary and missing value detection.
Interactive data visualizations.
Statistical analysis and correlation detection.
Time-series forecasting.
AI-generated business insights and recommendations.
AI-powered chatbot for querying the uploaded data.
Runs locally without paid APIs.

# ⚙️ Installation
Clone the repository:
git clone YOUR_REPOSITORY_LINK
Navigate to the project directory:
cd AI-Business-Data-Analyst
Create a virtual environment:
python -m venv venv
Activate the virtual environment:
venv\Scripts\activate
Install the required packages:
pip install -r requirements.txt
Install Ollama and download the model:
ollama pull llama3.1
Run the application:
streamlit run app.py
